# Poetry から uv への切り替え

## 概要

このプロジェクトのパッケージ管理ツールを Poetry から uv に移行する手順を説明します。

## 前提条件

- uv がインストールされていること
  - インストール方法: `curl -LsSf https://astral.sh/uv/install.sh | sh`
  - または: `pip install uv`

## 移行手順

### 1. Poetry から uv への自動移行

以下のコマンドで Poetry の設定ファイルから uv の設定ファイルに自動変換できます:

```bash
uvx migrate-to-uv
```

このコマンドは以下の処理を行います:
- `pyproject.toml` を uv 形式に変換
- `poetry.lock` から `uv.lock` を生成
- Poetry 固有の設定を削除または適切な形式に変換

### 2. 依存関係のインストール

移行後、以下のコマンドで依存関係をインストールします:

```bash
uv sync
```

このコマンドは `uv.lock` に基づいて仮想環境を作成し、すべての依存パッケージをインストールします。

### 3. 確認

仮想環境が正しく作成されたことを確認します:

```bash
# 仮想環境をアクティベート
source .venv/bin/activate

# Python バージョンの確認
python --version

# インストール済みパッケージの確認
uv pip list
```

## uv の主な利点

- **高速**: Rust で実装されており、Poetry や pip より大幅に高速
- **ロックファイル**: 決定的な依存関係の解決
- **互換性**: pyproject.toml の標準に準拠
- **シンプル**: より少ないコマンドで同等以上の機能

## よくあるコマンドの対応表

| 操作 | Poetry | uv |
|------|--------|-----|
| パッケージの追加 | `poetry add <package>` | `uv add <package>` |
| 開発用パッケージの追加 | `poetry add --group dev <package>` | `uv add --dev <package>` |
| 依存関係のインストール | `poetry install` | `uv sync` |
| スクリプトの実行 | `poetry run <command>` | `uv run <command>` |
| 仮想環境のシェル起動 | `poetry shell` | `source .venv/bin/activate` |
| パッケージの削除 | `poetry remove <package>` | `uv remove <package>` |
| ロックファイルの更新 | `poetry lock` | `uv lock` |

## トラブルシューティング

### 移行後にパッケージが見つからない場合

```bash
# キャッシュをクリア
uv cache clean

# 再度同期
uv sync --reinstall
```

### 仮想環境の場所を確認したい場合

```bash
uv venv --help
```

デフォルトでは `.venv` ディレクトリに作成されます。
